Sugar Coder 27B is i14's coding-specialized model, converted from a Qwen Coder 27B base and extended with i14's embedded tool system. Unlike traditional tool-calling setups, Sugar Coder's tools execute inside the model's own forward pass — not as external function calls — making tool invocation a native part of inference. This enables tighter, faster agentic coding loops without any external orchestration on your side.

## What Are Embedded Tools?

In a standard tool-calling workflow, the model emits a structured JSON payload, execution pauses, an external runtime runs the tool, and the result is fed back in a follow-up request. Every tool use adds a full round trip.

Sugar Coder 27B works differently. Its tools — including capabilities like code execution and search — run **inside the model's forward pass**. The model invokes them, receives their output, and continues reasoning in a single inference call. The result is:

- **No external orchestration required** — you don't need to build a tool-execution loop.
- **Lower latency per agentic step** — tool results are available within the same forward pass.
- **Tighter integration** — the model reasons over tool output as part of its native context, not as a bolted-on afterthought.

## Use via the API

Send a request to the shared i14 endpoint and set `model` to `sugar-coder-27b`.

```bash
curl https://api-dev.i14.ai/v1/chat/completions \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer $I14_API_KEY" \
  -d '{
    "model": "sugar-coder-27b",
    "messages": [
      {
        "role": "user",
        "content": "Write a Python function that parses a JSON file and returns all keys with null values."
      }
    ]
  }'
```

## Use via OpenAI SDK

Sugar Coder 27B is fully OpenAI API-compatible. Point the SDK's `base_url` at the i14 endpoint, pass your API key, and set the model to `sugar-coder-27b`.

```python
from openai import OpenAI

client = OpenAI(
    base_url="https://api-dev.i14.ai/v1",
    api_key="your-i14-api-key",
)

response = client.chat.completions.create(
    model="sugar-coder-27b",
    messages=[
        {
            "role": "user",
            "content": (
                "Write a Python function that parses a JSON file "
                "and returns all keys with null values."
            ),
        }
    ],
)

print(response.choices[0].message.content)
```
