The i14 API puts two frontier models behind a single OpenAI-compatible endpoint so you can switch between a large general-purpose language model and a tool-augmented coding agent by changing one parameter. **Sugar Glider 120B** is i14's own 120-billion-parameter architecture built for broad reasoning and generation tasks. **Sugar Coder 27B** is a coding agent—converted from a Qwen Coder 27B base—whose tools execute inside the forward pass, giving it the ability to write, run, and debug code without extra orchestration on your side. Both models are available at `https://api-dev.i14.ai/v1` the moment you create a free account.

## Access Options

You can start calling the i14 API in three ways:

- **Self-serve signup** — Create a free account at [platform-dev.i14.ai](https://platform-dev.i14.ai/) using Google, GitHub, or email. No credit card is required. Your API key is available immediately after sign-up.
- **OpenRouter** — If you already have an OpenRouter account, both models appear in the OpenRouter model catalog. Pass your OpenRouter key to `https://openrouter.ai/api/v1` and use the same model IDs.
- **Local weights** — Model weights for both Sugar Glider 120B and Sugar Coder 27B are published on Hugging Face, so you can run either model on your own infrastructure with standard tools like `transformers` or `vllm`.
